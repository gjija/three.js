CPU-written indirect dispatch

Reproduction for three.js #34864. The same program runs against either the unchanged upstream commit or the PR commit.

Run upstream baseline Run PR fix

A CPU-created buffer requests two workgroups of two invocations. Each invocation increments one output element. Then the CPU changes the count to three workgroups and sets needsUpdate = true.

The dispatch buffer is used only as the renderer.compute() dispatch argument. It is not bound as a shader input.

Requires a browser with WebGPU enabled. Each version loads its own source files exported from the pinned commit.
